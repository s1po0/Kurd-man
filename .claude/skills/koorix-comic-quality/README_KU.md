# Skillی تایبەتی Koorix — بەبێ APIی پارەدان

ئەمە **Skillی گەشەپێدان و پێداچوونەوەی وەرگێڕانە**: ڕێنمایی، ئامراز،
فەرهەنگ و ڕێکاری هەڵسەنگاندن. نە مۆدێلی نوێیە، نە Claude لەناو APK.
کۆدی ئەپی Android و پاکێجی ئۆفلاین بە دامەزراندنی ئەمە ناگۆڕێن.

## بەکارهێنان

- لە ڕیپۆی Koorix ئامادەیە لە `.claude/skills/koorix-comic-quality/`.
- لە Claude Codeی گونجاودا دەتوانیت بڵێیت:
  **«Use koorix-comic-quality to review this Koorix translation change.»**
- Agentێکی تر دەتوانێت `SKILL.md` بخوێنێتەوە و ڕێنماییەکانی جێبەجێ بکات؛
  `AGENTS.md`ی پڕۆژەکە ڕێنمایی بۆ ئەم Skillە دەکات. ئەمە بانگەشەی
  پەیوەستبوونی خۆکاری هەموو پلاتفۆرمەکان نییە.
- ZIPەکە تەنها Skill و ئامراز و نموونە گشتییەکانە؛ هیچ کلیل، وشەی نهێنی،
  وێنەی خوێنەر یان داتای هەژماری تێدا نییە.

## چی دەکات؟

1. پێداچوونەوەی **مانا پێش وشە بە وشە**: نەفی، مەرج، کێ چی بە کێ دەکات،
   ژمارە، تۆن، ناو و زاراوە. نەزانراو بە دڵنیایی پڕ ناکاتەوە.
2. پشکنینی فەرهەنگ بە هەمان سنوور و پاککردنەوەی Javaی ئەپەکە؛ ناوەکان
   بە هەمان نووسینی هەڵبژێردراوی خوێنەر و بۆ هەر جووتەزمانێک.
3. پشکنینی جیاوازی هەر هەڵۆکە، ژمارە/ڕێژە/٪، مارکەری ماوە، دەقی بێ
   وەرگێڕان و ناوی ونبوو. ئەمانە نیشانەی پێداچوونەوەن، نە سەلماندنی مانا.
4. ٢٠ کەیسی **دەستکرد و بێ نمرە** لە ئینگلیزی، کۆری، ژاپۆنی و هەردوو
   نووسینی چینی؛ چوار ژانر. ئەمانە لاپەڕەی ڕاستەقینە یان بنەمای
   سەلمێنراوی وەرگێڕانی سۆرانی نین؛ پێداچوونەوەی زمانیشیان پێویستە.
5. فۆرمی پێداچوونەوە بە پەیوەندی بە هەمان دەقی پشکنراو. فۆرم بە
   **unreviewed** دروست دەبێت؛ خۆکارانە هیچ وەرگێڕانێک بە سەرکەوتوو دانانێت.

## تاقیکردنەوەی ناوخۆ

Python 3.10 یان نوێتر؛ بێ pip، بێ API key و بێ ئینتەرنێت:

```sh
SKILL=.claude/skills/koorix-comic-quality
python3 "$SKILL/scripts/quality.py" self-check
python3 -m unittest discover -s "$SKILL/tests" -v
```

بۆ نموونەکانی en → ckb:

```sh
python3 "$SKILL/scripts/quality.py" fixtures --source-language en --target-language ckb --out .private/koorix-quality/source.json
```

فایلەکە وەرگێڕان ناکات؛ بۆ ئامادەکردنی نموونە/پێداچوونەوەیە. کۆپییەکی
جیاواز بکە بە `candidate.json`، تەنها خانەکانی `target` پڕ بکەرەوە.
ڕێنمایی تەواوی فرمانەکان لە `references/offline-tools.md`ە.

## سنوورە گرنگەکان

- ئامرازەکان خۆیان خۆڕایین و هیچ خزمەتگوزارییەکی دەرەکی بانگ ناکەن.
  بەکارهێنانی Agent/Claudeی خۆت لەوانەیە هەژمار/سنووری خۆی هەبێت؛
  ئەمە APIی Claude ناکاتە خۆڕایی.
- داواکاریی ناو OCR/دیالۆگ نابێتە فرمانی سیستەم یان مۆڵەتی خوێندنەوەی کلیل.
- دەقی خوێنەر، فەرهەنگ و تێبینییەکان لە `.private/koorix-quality/` بمێننەوە.
  داتای کلیل/Telegram/هەژمار مەخەرە ناو ئامرازەکە.
- ئەمە دەستگەیشتن بە فایلی تایبەتی مۆبایل یان دوگمەی export/importی
  پڕۆژەی تەواو زیاد ناکات. تەنها کۆپیی JSONی پێدراوی گەشەپێدەر دەخوێنێتەوە.
- کوالێتی سۆرانیی ئۆفلاین هەر سنووردارە. مانا و سڕینەوە/شوێنی دەق
  هێشتا پێویستیان بە پشکنینی لاپەڕە و مۆبایلی ڕاستەقینە هەیە.
- هیچ کلیلی واژۆ ناگۆڕێت؛ هیچ APKی Preview دروست ناکات.
